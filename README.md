# CelulasCervicales
rodrigoangulo-tech/Redes_Neuronales

El proyecto usa una red neuronal para la clasificación de células precursoras de cáncer cervical. 
El propósito es ayudar en la detección temprana de signos precancerosos reduciendo a la vez signos ambiguos.
EL modelo de la red neuronal está basado en MobileNetV3-Large está entrenado con APCEM-Enhanced Cervical Cytology Image Dataset (https://data.mendeley.com/datasets/snzb5g6ddy/2)
